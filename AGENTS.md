# AGENTS.md — Working History / Changelog

Log of completed sprints and notable decisions. Newest entries at the bottom.
Source docs live in `docs/` (sprint plan, tech spec, product design).

## Conventions

- One commit per sprint, pushed to `origin/main`.
- Every sprint must leave the repo green: `npm run lint` + `npm test` (backend pytest + frontend vitest).
- Root `package.json` exposes standard `install` / `build` / `test` / `start` scripts so Sentinel can extract commands automatically (see `docs/integration.md`, Tier 0).
- Backend venv lives at `.venv/` (root). Create with `npm run setup`.

## Sprint 1 — Database Schema (completed 2026-08-22)

**Delivered**
- All 16 SQLAlchemy 2.0 models in `backend/models/` per Tech Spec §8:
  teams, games, game_odds, raw_odds, injuries, raw_injuries, strategies,
  simulation_runs, simulation_results, system_play_results, ml_models,
  model_predictions, backtest_results, model_evaluations, portfolios, portfolio_items
- Full FK relationships, query-heavy-column indexes, timestamps with server defaults
- Alembic initialized (`backend/alembic.ini`, `backend/migrations/`); `env.py` reads DB URL from app settings unless overridden; initial autogenerated migration `ab54a48b74f6_initial_schema`
- Tests (`backend/tests/test_models.py`): metadata completeness, create-all, relationship round-trips, FK targets, index presence, clean `alembic upgrade head` on empty DB

**Verified**
- `pytest`: 9 passed; migration applies to an empty SQLite file producing exactly the 16 tables
- Alembic-generated migration code excluded from ruff (`extend-exclude = ["migrations"]`)

**Decisions / gotchas**
- SQLAlchemy annotation gotcha: a column named `date` shadows the `date` type during annotation evaluation → column silently became NOT NULL. Fixed by importing `from datetime import date as dt_date`. Watch for this pattern on any future column whose name matches its type.
- `Portfolio.model_id` FK exists per spec; added convenience `model`/`game` relationships on `Portfolio`/`PortfolioItem` used by ORM inserts.

**Out of scope (per plan)**: CRUD operations (Sprint 4), API endpoints (Sprint 5), simulation logic (Sprint 2)
